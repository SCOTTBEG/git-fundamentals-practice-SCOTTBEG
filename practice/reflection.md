## 1. What is the difference between a commit and a push?

Answer: The difference between a commit and a push is that a commit takes the changes and records then make a checkpoint from that local repository. A push uploads one or more local commits that has an already created remote branch.

## 2. Why work on a branch instead of directly on `main`?

Answer: Working form a branch rather than directly to main is to keep the code organize and safe. Further being able to keep the data from being leaked or corrupted by anything.

## 3. What does a pull request make possible?

Answer: A pull request allows the developers to review the code that is being changed from the main codebase. Mostly for peer code review and many more.
